# Plots

A plot shows numbers: data, a function, a simulation's output. Every plot is generated by a script in the repository, so anyone can rebuild it and get the same file.

## The rule

```
figures/src/running_mean.py   →   figures/running-mean.svg
```

- Python and Matplotlib, with the house style: `plt.style.use(STYLE)` where `STYLE` points at `assets/hypergraph.mplstyle` from this skill (copy it into the track as `figures/src/hypergraph.mplstyle` so the script runs without the skill installed).
- One script per figure, named after it with underscores. It writes exactly one SVG into `figures/` and nothing else.
- Fixed seed: `rng = np.random.default_rng(SEED)` with `SEED` a constant at the top.
- Save with the date stripped so the file only changes when the plot does: `fig.savefig(OUT, metadata={"Date": None})`.
- Runs from the track root: `python figures/src/running_mean.py`.
- Record it in `assets` with `kind: plot` and `source:` pointing at the script.

## What the style does, and what you still decide

The style sets the palette, type, line weights, spines, size (720×405 px) and SVG output with text converted to outlines. You decide:

- **Series.** Up to three, told apart by line style (solid, dashed, dotted) in ink, muted and construction grey, in that order of importance. More than three series means a different plot.
- **Labels.** Label lines directly at their ends with `ax.annotate` or `ax.text` instead of a legend. Axis labels in sentence case with units in parentheses: `Number of flips`, `Height (m)`.
- **No title.** The caption in the notes is the title.
- **Reference lines** (a true value, a bound): construction grey `#8A8A88`, 1px, dashed.
- **Areas** (a region under a curve, a confidence band): fill `#EBEBEA`, no outline, drawn below the lines.
- **Points** (data): small ink circles; for many points, `alpha` between 0.2 and 0.5 is allowed, and is the only use of transparency.
- **Ticks.** Few: let Matplotlib choose, then remove any that crowd. Use `MaxNLocator(5)` if needed.
- **Log scales** say so in the axis label: `Number of flips (log scale)`.

## Not allowed

Colormaps other than `Greys`, colour of any kind, grids (use reference lines for the values that matter), 3D plots, pie charts, dual y-axes, chart junk, and titles. A heatmap uses `Greys` with a labelled colour bar.

## Other tools

If a plot genuinely needs another tool (R, Julia, a JavaScript library), match the same spec: 720×405 px SVG, the palette, Geist, 1.5px lines, no title, direct labels, a committed script with a fixed seed. Say why in the pull request.
